# Barber Pro — تطبيق حجز العملاء (customer-booking-app)

هذا المشروع جزء من نظام صالون حلاقة كامل، منفصل عن لوحة الإدارة لكنه يتصل
بنفس مشروع Firebase. تعليمات الإعداد الكاملة موجودة في:

**`../README.md`** (الملف في جذر المشروع الكامل، فوق هذا الفولدر مباشرة).

راجع كمان:
- `../FIRESTORE_SCHEMA.md` — بنية قاعدة البيانات.
- `../CHANGES.md` — كل تعديل تم في إعادة البناء، وليه.

**مهم:** هذا التطبيق يتطلب تفعيل **Anonymous Authentication** من Firebase
Console قبل أن يعمل — بدونها سيفشل في قراءة أو كتابة أي بيانات.

## تشغيل سريع (بعد إعداد Firebase حسب README الرئيسي)

```bash
npm install
npm run dev
```

```bash
npm run build
```
